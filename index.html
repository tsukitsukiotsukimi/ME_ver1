#001Phase 01 / 要求定義と単位

力の単位：ニュートン

1 N = 1 kg·m/s²
実務で覚える数字
重力加速度 g = 9.80665 m/s²。実務の概算では 9.8 または 10 m/s²を使うことが多い。
ストーリー上の使いどころ
検体カップ、ハンド、リンクの重さを力に変換する最初の式。質量のままモーメント計算に入ると単位が崩れる。
ミニ例
0.25 kgのカップなら重力は約2.45 N。安全側概算では2.5 Nとして扱える。
落とし穴
kgfとNを混ぜない。1 kgfは約9.8 Nであり、1 Nではない。
#002Phase 01 / 要求定義と単位

モーメントの基本

M = F × r
実務で覚える数字
単位は N·m。rは力の作用線までの垂直距離。
ストーリー上の使いどころ
アーム先端の荷重が関節にどれだけ負担をかけるかを見る。小型アーム設計の最重要感覚。
ミニ例
2.5 Nの荷重が関節から0.30 mにあると、静的モーメントは0.75 N·m。
落とし穴
距離は部品長ではなく、力の作用線に垂直な距離。斜め荷重では成分分解する。
#003Phase 01 / 要求定義と単位

仕事率・機械出力

P = Fv = Tω
実務で覚える数字
ω[rad/s]を使う。rpmのままTωに入れない。
ストーリー上の使いどころ
搬送速度を上げたときに必要な機械出力を見積もる。モータのW数を見るときの基本。
ミニ例
関節トルク0.8 N·mで2 rad/sなら機械出力は1.6 W。効率込みなら入力側はさらに大きい。
落とし穴
定格出力だけで判断しない。低速では出力よりトルク制限が先に効くことが多い。
#004Phase 01 / 要求定義と単位

rpmからrad/sへの変換

ω = 2πn / 60
実務で覚える数字
100 rpm ≒ 10.47 rad/s。
ストーリー上の使いどころ
カタログの回転数rpmを、動力や加速度計算に使える角速度へ変換する。
ミニ例

落とし穴
rpmとrad/sの混同は、出力や慣性トルクを約9.55倍間違える原因になる。
#005Phase 01 / 要求定義と単位

先端荷重による静的関節トルク

T_static = (m_payload + m_hand) g L
実務で覚える数字
小型卓上アームでは、手先質量200〜500 gでもリーチが長いと無視できない。
ストーリー上の使いどころ
最初のモータ候補を絞るための粗い計算。垂直面で動くアームでは特に重要。
ミニ例
payload 0.20 kg、hand 0.15 kg、L=0.25 mならT=0.35×9.8×0.25=0.86 N·m。
落とし穴
リンク自重の重心位置も加える。先端荷重だけで計算すると関節トルクを過小評価する。
#006Phase 01 / 要求定義と単位

安全率

n = Strength / Load
実務で覚える数字
一般的な試作機の静的安全率は1.5〜3程度から検討。人身リスクがある場合は別基準。
ストーリー上の使いどころ
未知の荷重、組立ばらつき、衝撃、材料ばらつきを吸収するために使う。
ミニ例
計算応力80 MPa、材料の許容応力200 MPaなら安全率は2.5。
落とし穴
安全率を大きくすれば良いとは限らない。重量増、コスト増、応答低下を招く。
#007Phase 01 / 要求定義と単位

重心位置

x̄ = Σ(m_i x_i) / Σm_i
実務で覚える数字
質量が遠いほど関節モーメントと慣性が効く。
ストーリー上の使いどころ
リンク、ハンド、カバー、配線の重心を合成し、トルクと転倒を評価する。
ミニ例
0.3 kgが0.1 m、0.2 kgが0.3 mならx̄=(0.03+0.06)/0.5=0.18 m。
落とし穴
見た目の中心と重心は違う。モータ、減速機、カメラなど高密度部品の位置が支配的になる。

ミニ例
0.2 kgの部品を軸から0.25 m離すと、点質量近似だけでI=0.0125 kg·m²。
落とし穴
質量を少し軽くするより、軸に近づける方が効く場合が多い。
#009Phase 01 / 要求定義と単位

運動エネルギー

E = 1/2 mv², E = 1/2 Iω²
実務で覚える数字
衝突時のリスクやブレーキ負担は速度の2乗で増える。
ストーリー上の使いどころ
安全カバー、停止距離、非常停止時の負荷を考えるときに使う。
ミニ例
速度を2倍にすると運動エネルギーは4倍。軽量化より速度制限の方が効く場面がある。
落とし穴
低速だから安全と決めつけない。大きな慣性を持つ回転体は低速でもエネルギーを持つ。

効率の連鎖

η_total = η_1 η_2 η_3 ...
実務で覚える数字
ベルト0.95、ギヤ0.90、ねじ0.90なら総効率は約0.77。

#011Phase 02 / ロボットアームの幾何と運動

2リンク平面アームの順運動学

x = l1 cosθ1 + l2 cos(θ1+θ2), y = l1 sinθ1 + l2 sin(θ1+θ2)
実務で覚える数字
角度は計算ではrad。図面や仕様書ではdegでも、計算時に変換する。
ストーリー上の使いどころ
手先が要求範囲に届くか、干渉しないかを早期に確認する。
ミニ例
l1=150 mm、l2=120 mmなら最大リーチは270 mm。実際は手先形状と干渉で有効範囲が減る。
落とし穴
可動範囲は円だけではない。関節角制限、筐体干渉、ケーブル曲げ半径で削られる。

最大・最小リーチ

R_max = l1 + l2, R_min = |l1 - l2|
実務で覚える数字
完全に折り畳める理想2リンクの幾何範囲。

ミニ例
l1=160 mm、l2=110 mmならR_max=270 mm、R_min=50 mm。

ハンド長、関節ストッパ、ケーブル、カバーで理論値より狭くなる。
#013Phase 02 / ロボットアームの幾何と運動

ヤコビアンによる速度変換

v = J(q) q̇
実務で覚える数字
特異姿勢付近では小さな手先速度にも大きな関節速度が必要になる。
ストーリー上の使いどころ
手先速度仕様から関節モータ速度を求める。
ミニ例
手先100 mm/sを出すには、姿勢によって必要な関節速度が大きく変わる。
落とし穴
平均リーチだけで速度を決めない。最悪姿勢でモータ速度が足りないことがある。
#014Phase 02 / ロボットアームの幾何と運動

接線加速度と法線加速度

a_t = rα, a_n = rω²
実務で覚える数字
回転運動では速度一定でも中心向き加速度がある。
ストーリー上の使いどころ
カップをこぼさない動作、ハンド先端の慣性力を評価する。
ミニ例
r=0.25 m、ω=4 rad/sならa_n=4 m/s²で、約0.4 g相当。
落とし穴
速度一定なら力が不要と考えない。向きが変わるだけで加速度は発生する。
#015Phase 02 / ロボットアームの幾何と運動

エンコーダ角度分解能

Δθ = 2π / (N_count × G)
実務で覚える数字
Gはモータから出力軸までの減速比。4逓倍カウントならN_countに反映。
ストーリー上の使いどころ
位置決め精度の下限を把握する。
ミニ例
エンコーダ4000 count/rev、減速比50なら出力軸分解能は2π/200000=31 µrad。
落とし穴
分解能と精度は違う。バックラッシュ、弾性、原点誤差がある。

ねじ・ベルトの直動分解能

Δx = lead / (N_count × G)
実務で覚える数字
リード2 mm、2000 countなら理論分解能1 µm。
ストーリー上の使いどころ

ミニ例

落とし穴
理論分解能が1 µmでも、機械剛性や摩擦で1 µm精度になるわけではない。
#017Phase 02 / ロボットアームの幾何と運動

バックラッシュによる先端誤差

δ_tip ≈ L δθ
実務で覚える数字
δθはrad。1°=0.01745 rad。
ストーリー上の使いどころ
ギヤや関節ガタが手先位置に何mm出るかを判断する。
ミニ例
L=250 mm、ガタ0.2°ならδ=250×0.00349=0.87 mm。
落とし穴
角度をdegのまま掛けない。小角近似ではradが必須。
#018Phase 02 / ロボットアームの幾何と運動

小角近似

sinθ ≈ θ, tanθ ≈ θ
実務で覚える数字
概ね5°以下なら粗い見積もりに使いやすい。
ストーリー上の使いどころ
傾き、ガタ、直角度誤差を先端変位へ素早く換算する。
ミニ例
0.1°は0.001745 rad。長さ300 mmなら横ずれ約0.52 mm。
落とし穴
大角度まで小角近似を使わない。10°を超えると誤差が無視しにくい。
#019Phase 02 / ロボットアームの幾何と運動

誤差のRSS合成

e_RSS = sqrt(e1² + e2² + ...)
実務で覚える数字
独立したランダム誤差の合成に使う。最悪値は単純和。
ストーリー上の使いどころ
エンコーダ、組立、公差、センサノイズを合成して精度予算を作る。
ミニ例
0.05、0.08、0.10 mmの独立誤差ならRSSは約0.14 mm。
落とし穴
同じ原因で同方向にずれる誤差はRSSにしない。バイアスは別扱い。
#020Phase 02 / ロボットアームの幾何と運動

サンプリングとナイキスト

f_s > 2 f_max
実務で覚える数字
制御では最低2倍では不足。実務では対象帯域の10倍以上を目安にすることが多い。
ストーリー上の使いどころ
センサ取得、ログ、制御周期を決める。
ミニ例
10 Hzの振動を見たいなら最低20 Hz、制御に使うなら100 Hz以上を検討。
落とし穴
ログで見えていない振動は存在しないのではなく、サンプリング不足で消えている可能性がある。
#021Phase 03 / 静力学と梁の基礎

実務で覚える数字

ブラケット、支柱、ベースプレートの反力を求める出発点。
ミニ例
片持ち支柱の先端に10 Nがかかれば、固定部には10 Nの反力とF×Lのモーメントが出る。
落とし穴
力だけ釣り合っていてもモーメントが釣り合わなければ回転する。
#022Phase 03 / 静力学と梁の基礎

片持ち梁の先端たわみ

δ = F L³ / (3 E I)
実務で覚える数字
長さLは3乗で効く。少し短くするだけで大きく剛性が上がる。
ストーリー上の使いどころ
アームリンクや片持ちブラケットの先端変位を見積もる。
ミニ例
同じ断面なら、長さを300 mmから240 mmにするとたわみは約0.512倍。
落とし穴
材料を高級にする前に、Lを短くする、Iを増やす方が効くことが多い。
#023Phase 03 / 静力学と梁の基礎

両端支持梁の中央荷重たわみ

δ = F L³ / (48 E I)
実務で覚える数字
同じ荷重・長さ・断面なら片持ちより大幅に小さい。
ストーリー上の使いどころ
ガイドレールやシャフトを両端支持できるか検討する。
ミニ例
中央荷重の両端支持は片持ち先端荷重の1/16の係数。支持条件が効く。
落とし穴
実際の固定端・支持端の剛性が弱いと、理論通りにはならない。
#024Phase 03 / 静力学と梁の基礎

曲げ応力

σ = M c / I
実務で覚える数字
cは中立軸から外表面までの距離。
ストーリー上の使いどころ
リンク根元、ブラケット曲げ部、支柱固定部の強度を見る。
ミニ例
曲げモーメントが2倍なら応力も2倍。断面2次モーメントIを増やすと応力は下がる。
落とし穴
最大応力は外表面に出る。中立軸付近だけ見ても危険箇所は分からない。
#025Phase 03 / 静力学と梁の基礎

長方形断面の断面2次モーメント

I = b h³ / 12
実務で覚える数字
高さhが3乗で効く。板を立てると強い理由。
ストーリー上の使いどころ
アルミ板リンクの向き、リブ高さ、ブラケット形状を決める。
ミニ例

落とし穴
板厚を増やすだけが剛性設計ではない。断面高さを稼ぐ設計が強い。
#026Phase 03 / 静力学と梁の基礎

丸棒の断面2次・極2次モーメント

I = π d⁴ / 64, J = π d⁴ / 32
実務で覚える数字
直径dは4乗で効く。軸径を少し増やす効果は大きい。
ストーリー上の使いどころ
関節軸、シャフト、丸棒支柱の曲げ・ねじり計算に使う。
ミニ例
直径を10 mmから12 mmにするとIは約2.07倍。
落とし穴
中空軸では外径と内径の4乗差で決まる。軽量化と剛性の両立に有効。
#027Phase 03 / 静力学と梁の基礎

ねじりせん断応力

τ = T r / J

関節軸やカップリング軸がトルクに耐えるか見る。
ミニ例
同じトルクなら直径を少し上げるとd³で応力が下がる。
落とし穴
曲げとねじりが同時にかかる軸では、単独応力だけで判断しない。
#028Phase 03 / 静力学と梁の基礎

ねじり角

φ = T L / (G J)
実務で覚える数字
Gは横弾性係数。鋼は約77 GPa、アルミは約26 GPa。
ストーリー上の使いどころ
関節軸がねじれて位置決め誤差になるかを確認する。
ミニ例
長い細軸は強度が足りても角度剛性が不足することがある。
落とし穴
壊れない軸と、精度が出る軸は別。精密装置ではねじり角が支配的になる。
#029Phase 03 / 静力学と梁の基礎

Euler座屈荷重

P_cr = π² E I / (K L)²
実務で覚える数字

ストーリー上の使いどころ

ミニ例
長さが2倍になると座屈荷重は1/4。
落とし穴
材料強度に達する前に座屈する。細長い部材は降伏応力だけでは危険。
#030Phase 03 / 静力学と梁の基礎

面圧

p = F / A
実務で覚える数字
ピン穴なら概算 A = d × t。
ストーリー上の使いどころ
ピン穴、ブッシュ、樹脂受け、クランプ面がへたらないか確認する。
ミニ例
F=100 N、ピン径5 mm、板厚3 mmなら面圧は6.7 MPa。
落とし穴
平均面圧でOKでも、端当たりや傾きで局所面圧が高くなる。
#031Phase 04 / 強度・疲労・ピン周り

引張・圧縮応力

σ = F / A
実務で覚える数字
単位はPa。機械設計ではMPa = N/mm²が扱いやすい。
ストーリー上の使いどころ
リンク、ロッド、ボルト、支柱の基本応力を見る。
ミニ例
F=1000 N、A=50 mm²ならσ=20 N/mm²=20 MPa。
落とし穴
mm²で計算したらN/mm²=MPaになる。m²と混在させない。
#032Phase 04 / 強度・疲労・ピン周り

単純せん断応力

τ = F / A
実務で覚える数字
ピン、キー、リベット、薄板せん断で使う。
ストーリー上の使いどころ
ハンド爪のピンやストッパピンがせん断で切れないか見る。
ミニ例
直径4 mmピンの断面積は12.6 mm²。100 Nなら7.9 MPa。
落とし穴
単純せん断だけでなく、曲げ、面圧、疲労も同時に見る。
#033Phase 04 / 強度・疲労・ピン周り

von Mises相当応力

σ_v = sqrt(σ² + 3τ²)
実務で覚える数字
一軸応力σとせん断τの簡易合成。
ストーリー上の使いどころ
軸やブラケットで曲げとねじりが同時にかかる場合に使う。
ミニ例
σ=50 MPa、τ=30 MPaならσ_v≈72 MPa。
落とし穴
最大主応力だけで延性金属の降伏を判断すると危険な場合がある。
#034Phase 04 / 強度・疲労・ピン周り

降伏安全率

n_y = S_y / σ_v
実務で覚える数字

永久変形しないかを確認する。
ミニ例
S_y=250 MPa、σ_v=100 MPaならn_y=2.5。
落とし穴
材料名だけで強度を固定しない。熱処理、質別、板厚、規格で変わる。
#035Phase 04 / 強度・疲労・ピン周り

Goodman線図の基本

σ_a / S_e + σ_m / S_ut ≤ 1/n
実務で覚える数字
疲労は平均応力σ_mと応力振幅σ_aの両方を見る。
ストーリー上の使いどころ
アームが1日数千〜数万回動く場合、静的強度だけでなく疲労を確認する。
ミニ例
引張平均応力があると許容振幅は下がる。
落とし穴
『最大応力が降伏以下』だけでは疲労破壊を防げない。
#036Phase 04 / 強度・疲労・ピン周り

σ_max = K_t σ_nom

#037Phase 04 / 強度・疲労・ピン周り

切欠き感度を含む疲労応力集中

K_f = 1 + q(K_t - 1)
実務で覚える数字

q=0.8、Kt=2.5ならKf=2.2。
落とし穴
静的強度のKtと疲労のKfを混同しない。
#038Phase 04 / 強度・疲労・ピン周り

ピン穴の支圧応力

#039Phase 04 / 強度・疲労・ピン周り

二面せん断のピン

#040Phase 04 / 強度・疲労・ピン周り

#041Phase 05 / 締結・位置決め・接合

締付トルクと軸力

#043Phase 05 / 締結・位置決め・接合

ねじ有効かかり長さ

#044Phase 05 / 締結・位置決め・接合

メートル並目ボルトの有効断面積

#045Phase 05 / 締結・位置決め・接合

#046Phase 05 / 締結・位置決め・接合

#047Phase 05 / 締結・位置決め・接合

ノックピンの役割

#049Phase 05 / 締結・位置決め・接合

#053Phase 06 / 軸・ベアリング・ブッシュ
